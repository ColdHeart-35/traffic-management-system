Simulation

The analyst workbench page arrives in Sprint 2. For the Sprint 1 demo, use the API page:

  1. Sign in with POST /api/v1/auth/login as analyst / analyst123, then press Authorize and paste the token.
  2. POST /api/v1/simulation/networks/import-sample with {"name": "single_intersection"}.
  3. POST /api/v1/simulation/runs with {"networkId": 1, "durationSeconds": 3600, "seed": 42}.
  4. Read the delay, queue length and throughput in the response.

Simulation results are estimates and do not replace formal traffic-engineering sign-off.
